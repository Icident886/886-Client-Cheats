# 886 Client Cheats

This script is intended to be used in Garry's Mod.

## Installation

Place the script in:

C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\lua

Or place it in:

C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\lua\autorun\client

If you put it in the autorun/client folder, it will run automatically when the game starts.

## Manual Execution

Open the Garry's Mod console while in-game and run:

1. sv_cheats 1
2. lua_openscript_cl 886_Client_Cheats.lua
